## Prototype request

Create a simple working prototype that demonstrates the main value of this solution.

Please:

- Identify the smallest useful feature set.
- Build only the core user flow; avoid unnecessary features.
- Reuse the existing project structure, styles, and dependencies where possible.
- Keep the UI simple, clear, and easy to test.
- Use realistic sample data if a backend or database is not available.
- Handle basic loading, empty, validation, and error states.
- Keep the implementation clean and easy to extend.
- Explain how to run and test the prototype.

Before making changes, briefly state:

1. What the prototype will demonstrate.
2. Which files or components you will create or update.
3. Any assumptions you are making.

Then implement the prototype. After implementation, verify that the main flow works and summarize:

- What was built.
- How to run it.
- What remains outside the prototype scope.

If the requirements are unclear, ask only the smallest number of questions needed to start. Otherwise, make reasonable assumptions and proceed.
